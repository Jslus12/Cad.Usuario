# 📋 Cadastro de Usuário

Este é um projeto simples de cadastro de usuários desenvolvido com **HTML, CSS e JavaScript**. Ele permite realizar o cadastro e validação básica de dados, simulando um sistema inicial de autenticação.

## 🚀 Funcionalidades

* Cadastro de usuário
* Validação de campos obrigatórios
* Navegação entre páginas (login → cadastro)
* Estrutura simples para aprendizado de front-end

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📁 Estrutura do projeto

* `index.html` → Tela inicial / login
* `Cadastro.html` → Tela de cadastro
* `style.css` → Estilização
* `main.js` → Lógica do sistema
* `monte.jpg` → Imagem utilizada
* `LEIAME.md` → Documentação

## ▶️ Como executar

Basta abrir o arquivo `index.html` em qualquer navegador.

## 📌 Observações

Este projeto tem fins acadêmicos e pode ser melhorado com:

* Integração com banco de dados
* Sistema real de autenticação
* Melhor validação de dados
